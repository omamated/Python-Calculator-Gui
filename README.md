# Python-Calculator-Gui
This is a simple python gui calculator made by me! it is a basic calculator and can do anything the default windows calculator can do.
I made this project because I wanted to get back into my coding-flow so I decided to a little simple project without ai and copying. This code was fully written by me.

# Run the Calculator
To Run the calculator download and run the .exe file or download the python file and run it.

'''terminal
git clone https://github.com/omamated/Python-Calculator-Gui.git
cd Python-Calculator-Gui
python Calculator.py
'''
